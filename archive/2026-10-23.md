## 2. 从模型到筛查现场：Google 公布结核病 AI 应用进展

## 5. NVIDIA 扩展 Nemotron 检索系列：嵌入、重排和文档提取

![Agent 检索链路的三个组件。嵌入模型：8B / 1B，多模态检索；重排模型：8B，相关性重排；Parse 模型：631M，文档提取与解析](https://caixypromise.github.io/seven-tech-newsroom/assets/visuals/nemotron-retrieval.svg)

NVIDIA 扩展了 Nemotron 3.5 检索系列，推出覆盖嵌入、重排和文档解析的新组件，面向需要从材料中查找证据的 Agent 工作流。

这批组件包括 8B 与 1B 级嵌入模型、8B 重排模型，以及 631M 参数的 Parse 模型，官方也提供了部署和适配入口。各组件分别处理检索链路中的不同环节，公布的性能成绩来自 NVIDIA 报告，不能直接等同于整套 Agent 的准确率。

## 6. Copilot 用量 API 纳入 OpenCode 等客户端

![用量报告增加客户端维度。报告维度：按客户端，totals_by_client；统计内容：请求与会话，并按模型拆分用量；报告窗口：1 日 / 28 日，访问需相应查看权限](https://caixypromise.github.io/seven-tech-newsroom/assets/visuals/copilot-client-metrics.svg)

GitHub 用量 API 更新；组织内数据，不是公开行业排名。

GitHub 扩展了 Copilot 用量 API，把 OpenCode 等部分 IDE 以外客户端的使用情况纳入组织报告。新增的 totals_by_client 字段按客户端展示成功请求数、会话数，以及各模型的用量。

这些字段适用于 1 日和 28 日等报告，需要相应的管理或指标查看权限。它们反映的是组织授权范围内的使用情况，其中的请求数也不等于用户输入提示词的次数。

## 7. Google 开源 Elephant-Goldfish：先明确设计，再分离验证

![把设计与独立评审连接起来。设计会话：共同梳理设计，持有设计上下文；文档产出：明确设计文档，为后续实现提供依据；评审会话：分离上下文验证，优先集成 Antigravity](https://caixypromise.github.io/seven-tech-newsroom/assets/visuals/google-egm-plugin.svg)

Google 10 月 22 日公告；插件按 Apache 2.0 许可开源。

Google 在 10 月 22 日介绍并开源了 Elephant-Goldfish Model 插件，尝试把 AI 编程中的设计和验证安排到不同会话中：先共同梳理设计、形成文档，再由分离上下文的会话开展评审。

插件采用 Apache 2.0 许可，优先集成 Antigravity。此次发布给出了一套工具和工作流，实际能改善多少代码质量，还需要在具体项目中验证。

分类：开源；状态：插件开源；原文日期：2026-10-22。

来源：[Google Open Source](https://opensource.googleblog.com/2026/10/)
