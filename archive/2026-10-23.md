## 1. Kimi K3.1 Pro 获新评测：Agent 能力提升，权重仍待公开

Artificial Analysis 发布 Kimi K3.1 Pro 评测，报告其综合指数为 55。评测时模型权重尚未公开，应将 API 发布与权重开放分开看待。

- 评测报告称，Terminal-Bench 4.0 得分从 K3 的 13% 提升到 67%。
- 报告列出的上下文为 1M Token，输入／输出标价分别为每百万 Token 2／10 美元。

分数反映该评测及对应设置，不能直接代替所有任务中的实际表现；权重状态以来源文章当时的披露为准。

## 2. 从模型到筛查现场：Google 公布结核病 AI 应用进展

Google Research 介绍与 Nexus AI 等伙伴推进胸片辅助筛查的进展，并讨论 MedGemma 等开放模型与咳嗽音频研究。

- Google 称，合作工具已用于约 40 家医疗设施，评估胸片超过 25,000 张。
- 文章区分已部署的胸片工具和仍在积累临床证据的音频筛查研究。

这是机构公布的项目进展。筛查结果仍需临床专业人员判断，不应把模型可用等同于独立诊断能力。

分类：研究；状态：应用进展；原文日期：2026-10-23。

来源：[Google Research](https://research.google/blog/bringing-foundational-models-to-the-front-lines-of-tb-screening/)

## 3. GitHub 把 Teams 通知与 Copilot 代码任务连起来

更新后的 GitHub Teams 应用将通知和 Copilot 入口合并。团队可以从问题通知发起代码处理，再回到常规 PR 审查流程。

- 官方描述的流程包括：收到 Issue 通知、提及 GitHub 发起处理、生成 PR 后由团队审查。
- 旧版 GitHub 应用计划于 11 月 16 日退役，已有用户需核对使用的是哪一版。

具体功能取决于 GitHub 账户、仓库和产品可用条件；生成 PR 后仍包含测试与合并步骤。

分类：产品；状态：产品更新；原文日期：2026-10-23。

## 4. OlmoEarth 1.3 发布全球卫星嵌入与地图探索工具

Ai2 发布 OlmoEarth 1.3，并分享全球预计算卫星嵌入和浏览器地图工具，降低分析土地与环境变化的入门门槛。

- 官方说明数据采用 10 米空间分辨率，提供 64 和 128 维嵌入。
- 配套页面链接模型、技术报告、数据、代码和 Embeddings Explorer。

嵌入是可复用特征，不是对每一类地理问题都已完成验证的结论。使用模型和数据前仍需查看各自许可。

分类：开源；状态：模型与数据发布；原文日期：2026-10-22。

来源：[Ai2](https://huggingface.co/blog/allenai/olmoearth-v1-3)

## 5. NVIDIA 扩展 Nemotron 检索系列：嵌入、重排和文档提取

NVIDIA 发布 Nemotron 3.5 检索组件，覆盖多模态检索、相关性重排和文档解析，面向需要读取证据的 Agent 工作流。

- 新组件包括 8B 与 1B 级嵌入模型、8B 重排模型，以及 631M 参数的 Parse 模型。
- 官方同时给出模型、部署和适配入口；性能结果为厂商报告。

不同组件解决不同环节的问题。不能用其中某一个检索测试的成绩推断端到端 Agent 的准确率。

分类：模型；状态：模型发布；原文日期：2026-10-21。

来源：[NVIDIA](https://huggingface.co/blog/nvidia/nemotron-retriever-world-class-agentic-retrieval)

## 6. Copilot 用量 API 纳入 OpenCode 等客户端

GitHub 为 Copilot 用量报告增加按客户端统计的字段，让组织能看到部分 IDE 以外工具产生的模型请求和 Token 使用。

- totals_by_client 包含客户端、成功请求数、会话数，以及按模型拆分的用量。
- 适用于 1 日和 28 日等报告，访问需要相应管理或指标查看权限。

这些是组织授权范围内的用量数据，并非公开行业榜单；请求次数也不能直接当作用户提示次数。
